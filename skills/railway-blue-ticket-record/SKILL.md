# 蓝色铁路乘车记录

使用随包 v03 底图、固定字段坐标和本地 Pillow 渲染器。每张票根显示「个人行程记录」，右侧为固定装饰图案。需要正式报销时保留铁路开具的电子发票原件。

## 整理行程

- 普通记录需要乘车日期、车次、出发站和到达站。改签费需要费用日期和金额。缺少选填信息时留空。字段、座位格式和证件显示选项见[输入规则](references/input-and-layout.md)。
- 订单截图按行程卡片和乘客拆分，读取发车时间和各自的票面金额。积分页读取白色详情弹窗里的乘车日期、车次和路线。仅有积分列表时请用户补详情；积分到账日、有效期与积分数分别属于账户信息。
- 铁路电子发票优先在本机读取内嵌 XML 的行程、票价和乘客字段。无附件时核对页面文字；扫描件可用下方网页版的本地 OCR。多页按原序整理。区分乘车日期与开票日期、乘客与购买方、票价与不含税金额。
- 需要查询缺项时，先匹配乘车当日资料，再按用户选择采用现行参考值。时刻须匹配车次、方向、发到站；票价还须匹配席别及有价差的铺位。保留来源、适用日和查询日，参考值与实际支付分别标明。示例车次 `DEMO01` 跳过查询。
- 批量默认乘车人只补空值，已有其他乘客姓名时保留其信息。自动打码为默认选项，仅在用户明确选择原样显示时填写 `identityMode: raw`。

## 生成与检查

从本技能目录运行，Python 3.9+ 需安装 Pillow 和中文字体。Windows 可使用已有宋体，Linux 可用 Noto CJK TTC。首次使用可直接运行虚构示例。

```sh
python -m pip install "Pillow>=9.2"
python scripts/render_tickets.py assets/demo-trip.json --out-dir output
```

把示例路径换成 UTF-8 JSON 对象或数组即可批量生成。每条输出 1586 × 992、300 DPI 的 PNG 和同名 `.record.json`（含来源和图片 SHA256）。要修订同一条记录，使用新的输出目录；同名文件受覆盖保护。检查日期、路线、席位、金额和证件显示，再交付对应文件。

需要直接识别文件、两列拼图或 A4 两列五行排印时，可在[配套网页版](https://lgmhg.github.io/railway-travel-cards/)使用「批量导入行程」或「电子发票」。网页可导入原批量 JSON。Python 命令负责离线渲染已整理的记录。
