# 12306铁路报销凭证打印生成

在浏览器里填写个人乘车记录，或导入已经从铁路 12306 下载的官方 PDF，预览、排序并排印。手填票面带有“个人行程记录”字样，仅用于旅行留念。需要报销时请使用 12306 开具的电子发票。[铁路 12306 电子发票说明](https://passport.12306.cn/otn/view/invoice_index.html)

## 怎么用

1. 选择“填写行程”，输入乘车日期、车次、出发站和到达站。时间、席别、车厢、座位、票价、姓名和已打码证件号均可留空。卧铺可选铺位，无座自动隐藏座号。添加改签费时填写日期与金额即可。
2. 也可以选择“导入官方 PDF”。支持多文件、多页和不同页面尺寸，导入后无需重新填写票面字段。
3. 在清单中勾选记录，上移或下移调整顺序。点击记录名称查看票面，手填项可以再次编辑。
4. 选择输出方式，查看排版预览，导出文件。刷新或关闭页面会清空本次录入和导入的内容。

| 导出方式 | 文件内容 |
| --- | --- |
| A4 十张打印 PDF | 纵向两列五行。蓝色记录图宽 85.6 毫米，纵横间隔均为 2 毫米。超过十张自动分页，末页保留原位置。PDF 来源页面等比放入格内。 |
| 官方 PDF 原尺寸 | 仅勾选导入页时默认选中。按页面原尺寸和清单顺序输出。单份完整原序文件直接返回原 PDF。 |
| 单张 PNG | 勾选一项。手填记录为 1586 × 992 像素，导入页保持原比例。 |
| 多张拼图 PNG | 勾选至少两项，按清单顺序从左至右双列拼接。长拼图会等比降低分辨率，以适应浏览器画布。 |

打印 A4 十格 PDF 时选择 **A4、纵向、实际大小／100%**。导入的整页发票缩入十格后字会变小，可改选原尺寸。原文件请自行留存。

## 本地运行

需要 Node.js 24、npm 和静态 HTTP 服务。以下示例使用 Python 3 启动本地预览。

```sh
npm ci --omit=optional --ignore-scripts
npm run build
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

浏览器打开 `http://127.0.0.1:8000/`。可从任意静态 HTTP(S) 站点的子目录提供构建好的 `dist/`。页面、字体、PDF.js 工作线程和解码资源均由本站提供，用户填写的资料和导入的 PDF 只在浏览器内存中处理。

## GitHub Pages

在仓库 Settings → Pages 中选择 GitHub Actions 作为发布来源。推送到 main 或手动运行 Publish GitHub Pages 工作流即可构建并部署静态站点。
